## この版の主な変更（0.1.1-beta.1 から）

<!-- 出すたびに、この版の変更に書き直す（make publish が、リリースの説明の先頭に入れる） -->

0.1.0・0.1.1 を入れている場合は、アプリの中から更新できます（メニューバーのアイコン →「アップデートを確認…」。自動でも確かめます）。画面収録などの許可は、取り直さずにそのまま使えます。

### 変わったこと

- 使い方・見た目・動きは変わりません。開発と配布の手順を整えた版です

**English:** Nothing changes in how Pinshot looks or works; this release only tidies up the development and release process. If you have 0.1.0 or 0.1.1, you can update from the menu bar ("アップデートを確認…"); permissions such as Screen Recording are kept.
