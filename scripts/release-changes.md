## この版の主な変更（0.1.0-beta.1 から）

<!-- 出すたびに、この版の変更に書き直す（make publish が、リリースの説明の先頭に入れる） -->

0.1.0 を入れている場合は、アプリの中から更新できます（メニューバーのアイコン →「アップデートを確認…」。自動でも確かめます）。画面収録などの許可は、取り直さずにそのまま使えます。

### 変わったこと

- 動いている Pinshot への割り込みや、部品の差し込みを断る macOS の仕組み（Hardened Runtime）をオンにしました（ほかの Pin シリーズと同じ）。使い方は変わりません

**English:** Pinshot now runs with the Hardened Runtime enabled, like the other Pin series apps. Nothing changes in how you use it. If you have 0.1.0, you can update from the menu bar ("アップデートを確認…"); permissions such as Screen Recording are kept.
